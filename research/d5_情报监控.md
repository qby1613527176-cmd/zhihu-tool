## 设计

- **监控源**：纯 HTTP 搜索（不开浏览器）——关键词集 [山茶油 / 油茶 / 油茶籽 / 油茶产业 / 茶油价格]
- **快照**：每词前 20 条（id/标题/赞数/时间）存 SQLite
- **变更检测**：全局按条目 id 判新（跨词重复正确吸收）——老条目复现零误报

## 用法与调度建议

```bash
python3 watch.py run         # 采集一轮快照
python3 watch.py new         # 只看新增
python3 watch.py history     # 历史轮次
python3 watch.py demo-diff   # diff 演示
```

- 建议频率：每日 1-2 轮（5 词 × 2 请求 ≈ 10 req/轮，日预算的零头）
