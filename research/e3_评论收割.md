## 2. 纯 HTTP 可行性探测（任务①）

### 2.1 探测设计

- 端点：`/api/v4/comment_v5/answers/{aid}/root_comment?order_by=score&limit=20&offset=0`

**实测通过**：comment_v5 API 纯 HTTP 直打 200（带 FastClient 签名），无需浏览器。
