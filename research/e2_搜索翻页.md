# E2 · 搜索结果全量翻页（纯 HTTP）

> 2026-11-06 · 子代理 E2 失败(error)·主代理亲自完成

## 分页机制实测（probe：山茶油，offset=0/20/40）

| offset | 条数 | 新 id | is_end |
|---|---|---|---|
| 0 | 20 | 20 | False |
| 20 | 20 | 18 | False（页界重叠 2 条）|
| 40 | 20 | 18 | False |

- **offset 步进有效**（与 feeds 的 cursor 链不同！feeds 手工 bump offset 会被忽略，搜索不会）
- paging.next 指向 api.zhihu.com 域（带 search_hash_id），但 www.zhihu.com 域 offset 翻页同样通
- 页界有 ~10% 重叠 → 必须按 id 去重

## 实现

`zhihu_fast.FastClient.search_all(query, max_items)`：offset 步进 20/页 + 全局 id 去重，
终止条件 is_end / 空页 / 整页无新。实测「油茶」50 条/3 页/truncated 正确标记。
